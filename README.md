# Blue Mountains Bushfire Risk Assessment
Interactive GIS map — Blue Mountains LGA, New South Wales

## Description
Weighted overlay index combining six spatial factors: NDVI (30%), Slope (25%), 
WUI (15%), Bush Fire Prone Land (10%), NBR Sentinel-2 (10%), Aspect (10%).
Five risk classes calibrated against 403 historical NPWS fire records.

## Data Sources
- Sentinel-2 L2A (Copernicus)
- SRTM DEM (Geoscience Australia)
- NSW RFS Bush Fire Prone Land
- NPWS Fire History (NSW SEED)
- OpenStreetMap
